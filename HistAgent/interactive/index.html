01

Install

From the HistAgent repository root, create an environment and install the Agent Module.

python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m pip install -r examples/chat/requirements.txt
02

Configure and start

Copy the template, add your model endpoint, then start the service. The data bundle downloads on first run.

cp examples/chat/.env.example examples/chat/.env
python examples/chat/run_chat.py
03

Connect

Local pages detect 127.0.0.1:7860. A deployed site can set the public service origin in its page head.

<meta name="histagent-chat-origin"
  content="https://your-agent-service.example">
